## 1. Статистики для кластеров

### 1.1. Внутрикластерные

- **Размер** — число объектов в кластере (среднее, медиана, std, min, max).
- **Inertia (SSW)** — сумма квадратов расстояний всех точек до центроида кластера.
- **Среднее / медианное расстояние до центроида** — характеризует компактность.
- **Радиус кластера** — максимальное расстояние от точки до центроида.
- **Плотность** — число объектов, делённое на объём (или площадь) кластера.

### 1.2. Межкластерные

- **Silhouette score** — средний и per-cluster; показывает, насколько объекты ближе к своему кластеру, чем к соседнему.
- **Davies-Bouldin index** — среднее отношение внутрикластерного разброса к межкластерному расстоянию (чем меньше — тем лучше).
- **Calinski-Harabasz index** — отношение межкластерной дисперсии к внутрикластерной (чем больше — тем лучше).
- **Dunn index** — отношение минимального межкластерного расстояния к максимальному внутрикластерному диаметру.
- **Расстояния между центроидами** — min, mean, max; характеризуют разделённость кластеров.

### 1.3. Распределительные (баланс размеров)

- **Коэффициент вариации (CV)** — std / mean размеров кластеров (уже рассчитан).
- **Gini coefficient** — мера неравномерности распределения размеров (0 = идеально равные, 1 = всё в одном кластере).
- **Энтропия размеров** — информационная мера равномерности распределения.
- **Доля outlier-кластеров** — процент кластеров, размер которых выходит за пределы ±2σ от среднего.

## 2. Графики визуализации

### 2.1. Распределение размеров кластеров

| График | Описание | Когда полезен |
|--------|----------|---------------|
| **Гистограмма размеров** | Распределение числа объектов по кластерам (отдельно для каждого уровня) | Оценка формы распределения, выявление перекосов |
| **Boxplot размеров** | 3 уровня рядом на одном графике | Быстрое сравнение медианы, разброса и выбросов между уровнями |
| **Violin plot** | Boxplot + плотность распределения | Более детальная картина формы распределения |
| **Rank-size plot** | Кластеры отсортированы по убыванию размера (лог-лог шкала) | Выявление степенного закона, доминирования крупных кластеров |
| **CDF (кумулятивная функция распределения)** | Накопленная доля кластеров по размеру | Сравнение «хвостов» распределений между уровнями |

### 2.2. Качество кластеризации

| График | Описание | Когда полезен |
|--------|----------|---------------|
| **Silhouette plot** | Горизонтальные полосы по кластерам, отсортированные по silhouette value | Визуальная оценка качества каждого кластера, выявление «плохих» кластеров |
| **Silhouette score per cluster (bar chart)** | Средний silhouette для каждого кластера | Ранжирование кластеров по качеству |
| **Elbow plot** | Inertia vs. число кластеров k | Обоснование выбора оптимального k (если проводился подбор) |
| **Scatter: inertia vs. размер кластера** | Зависимость внутрикластерной ошибки от числа объектов | Поиск кластеров с аномально высокой ошибкой |

### 2.3. Структура и пространственное расположение

| График | Описание | Когда полезен |
|--------|----------|---------------|
| **t-SNE / UMAP 2D-проекция** | Все объекты на плоскости, раскрашенные по кластерам | Визуальная проверка: действительно ли кластеры разделены |
| **Heatmap расстояний между центроидами** | Матрица попарных расстояний | Выявление близких (потенциально сливаемых) кластеров |
| **Dendrogram** | Дерево иерархии разбиений (Bisecting K-Means естественно порождает его) | Понимание порядка и логики разбиений |
| **PCA biplot** | Проекция на первые 2 главные компоненты с осями признаков | Интерпретация: какие признаки разделяют кластеры |

### 2.4. Иерархия уровней (Large → Medium → Small)

| График | Описание | Когда полезен |
|--------|----------|---------------|
| **Sankey / Alluvial diagram** | Потоки объектов: как Large-кластеры дробятся на Medium, затем на Small | Отслеживание «судьбы» объектов через уровни |
| **Treemap** | Вложенные прямоугольники: Large → Medium → Small | Наглядная иерархическая структура с пропорциональными площадями |
| **Sunburst chart** | Кольцевая диаграмма с уровнями от центра к краю | Альтернатива treemap для иерархической декомпозиции |
| **Stacked bar chart** | Для каждого Large-кластера — столбец, разбитый на Medium-подкластеры | Как именно дробится каждый крупный кластер |

### 2.5. Сравнение уровней

| График | Описание | Когда полезен |
|--------|----------|---------------|
| **Grouped bar chart** | min / mean / median / max размера по уровням | Сводное сравнение масштабов |
| **Radar chart** | Несколько метрик (CV, Silhouette, Gini, …) для каждого уровня | Многомерное сравнение качества уровней |
| **Table heatmap** | Таблица метрик с цветовой кодировкой | Компактный обзор всех статистик по уровням |

## 3. Рекомендации по приоритету

Наиболее информативные визуализации для данной задачи:

1. **Sankey diagram** — показывает связь между уровнями иерархии, как объекты перетекают из Large в Medium и Small.
2. **Silhouette plot** — объективная оценка качества кластеризации на каждом уровне.
3. **Violin / Boxplot размеров** — быстрая оценка баланса и выбросов.
4. **t-SNE / UMAP** — визуальная проверка разделимости кластеров.
5. **Dendrogram** — логика разбиений Bisecting K-Means.

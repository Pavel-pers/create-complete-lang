# Визуализация и подведение статистики финальных кластеров
## Входные данные
Использовать нужно кластериазацию полученную в claude-experements/eng-corpus-wishart и описаную в claude-report.md
## Формат
Оформить нужно в jupiter notebook, построение графиков через matplot/seaborn
## Визуализация 
Графики должны быть понятны, для этого ты будешь запускать их построение и делать вывод о кластеризации, по полученнвм графикам, если не получилось или затруднительно увидеть закономерность повторить еще раз
## Разделение на части
Эксперементы и статистику нужно подвести для всех 3-х кластеров small/medium/large, для этого предалается разделить ноутбук на три части для каждого из кластера
## Сокращение колличество кластеров
Для артефактов кластеризации где большое колличество кластеров в графиках где визуализируются каждый из кластеров можно сократить кол-во до топ-20 по размеру, на твое усмотрение
## Данные для визуализации
В артефактах помимо разбиения хранятся еще дополнительная информация по типу плотности и типов, ее тоже можно и нужно использовать
## Предложения для графиков
Помимо своих графиков. Можешь использовать идеи из cluster_analysis_guide.md. Еще добавлю что нужно добавить визуализацию того как кластеры соотносятся с друг другом. Так же можно визуализировать в двумерном пространстве, облака слов и выделить центроиды чтобы было видно на сколько плотный тот или иной кластер. Для получения дополнительной информации и идей для визуализации можно посмотреть работы в интернете
## Статистики и метрики
Предложение по стастикам так же представленна в файле cluster_analysis_guide.md. Но больше упор стоит сделать на графики, часть со статистиками нужно расположить в начале каждого блока про кластер. Обязательно должны быть включены метрики качества кластеризации.
## Выводы
Для каждого графика нужно сделать краткий вывод(сами выводы буду делать я, ты должен поработать чтобы были визуально были показательны), так это будет контролировать что графики визуально понятны.
